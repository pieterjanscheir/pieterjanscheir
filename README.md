# Hi, I'm Pieter-Jan 👋

AI-first full-stack developer from Belgium. I build web applications with **TypeScript, React and Next.js**, mostly for the legal and public sector.

- 🏢 Software engineer at **LYNX**
- ⚖️ I build free legal-tech tools for Belgian lawyers, bailiffs, courts and judicial administrators
- ♿ I build and audit interfaces against **WCAG 2.2 AA** and know the European Accessibility Act and EN 301 549
- 🤖 I use Claude Code, Cursor and Codex every day, and I build MCP connectors so AI assistants can use my tools

## Featured work

| Project | What it does |
| --- | --- |
| [RPV Calculator](https://rpv-calculator.be) | Calculates the Belgian procedural indemnity (rechtsplegingsvergoeding), indexed to the CPI for any date. Comes with an MCP connector for Claude, ChatGPT and Mistral. |
| [Bewindvoeringen.be](https://www.bewindvoeringen.be) | Information platform and fee calculator for court-appointed administrators. ([public issue tracker](https://github.com/pieterjanscheir/vergoedingBewindvoerderPublicIssueTracker)) |
| [GDW Scheir](https://gdwscheir.be) | Bailiff's office website with free tools for debt claims, interest and lump-sum compensation. |
| [CourtBudget](https://courtbudget.vgprovl.be/) | Budget management for the justice of the peace courts and police court of East Flanders. |
| [Travel Allowance Calculator](https://scheir.eu/en/projects/travel-allowance-calculator) | Indexed travel costs for court staff, based on official Statbel CPI data. |
